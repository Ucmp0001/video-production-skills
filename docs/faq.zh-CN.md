# 常见问题：卡在哪一步，就看哪一项

[中文首页](../README.md) · [English](faq.en.md) · [新手教程](getting-started.zh-CN.md)

## Skill 到底是什么？装好就能一键出片吗？
Skill 是给 AI 助手的工作说明，像“这道工序怎么做、交什么、怎么检查”的操作手册。它不是模型、软件账号或视频生成器。助手读取后可以按步骤工作；真正配音、渲染或生成视频，还需要对应工具和可用账号。

## 我不会代码，要装 Git、Python、FFmpeg 吗？
第一份文字练习都不需要。用 GitHub 的 Download ZIP 下载，再手动复制技能文件夹即可。Python 3.10+ 只用于本仓库的安装器和检查脚本；Git 是可选下载/更新方式；FFmpeg/ffprobe 等媒体工具到实际需要时再安装。

## 命令到底输入在哪里？
安装软件、`py ...`、`python3 ...`、`claude --version` 输入系统终端。Windows 是 PowerShell，macOS 是“终端”。“使用这个技能帮我写稿”输入 AI 聊天框。不要把两种输入位置混在一起。

## 助手说找不到技能
先确认打开的是安装技能的项目文件夹；再确认目标结构是 `.agents/skills/技能名/SKILL.md`（Codex）或 `.claude/skills/技能名/SKILL.md`（Claude Code），没有重复嵌套。重启或新开会话后重试。仍不识别时，让助手读取该文件的实际路径，并列出读到的输入。发现方式随客户端变化，普通网页聊天不会自动读取本机目录。

## 找不到 examples 文件
这是仓库附带的练习资料，不在单个技能的安装目录里。练习时打开解压后的仓库根目录，确认 `examples` 直接位于这一层。自己的项目可以使用自己的资料，或把练习文件复制过去。

## Python / py / python3 提示找不到
手动复制技能即可继续文字练习。如需脚本，从 Python 官方页面安装3.10+，重新打开终端，再试本机实际可用的命令。用它替换教程中的 Python 命令名。`can't open file` 通常是当前目录不对：应先进入有 `scripts` 的仓库根目录。

## 安装器说目标已存在，是失败了吗？
它是在保护已有技能。不会覆盖你改过的文件，也不会先装一半再发现冲突。先比较旧版；新手可在一个新的练习项目里安装。想更新时先备份自己的修改，再明确替换所需目录；不要盲目删除整个 skills 目录。

## 为什么输出不是我想要的语言？
提示词里写清“用中文回答”或“reply in English”。每个技能共用 `SKILL.md` 发现入口，英文正文在 `SKILL.en.md`，英文模板在 `references/*.en.md`。复制整个技能文件夹，不要只复制某个 Markdown 文件。

## 能用手机里的 ChatGPT 控制吗？
手机可以是远程入口，但前提是你自己的客户端、电脑或云端执行环境已经连接，并且那个执行环境能读取项目和技能。把文件复制到电脑，不代表手机普通聊天会自动读到。仓库不提供远程连接功能；先用电脑完成练习，再根据所用客户端的官方远程说明配置。

## 不开 Claude 网页、用其他服务接入可以吗？
Claude Code 是客户端，模型服务是另一层；能否使用某个模型取决于服务支持、账号权限与实际返回。按照你所用客户端和服务的正式说明配置。本仓库不提供中转服务，不保证某个模型可用，也不会索取你的密钥。接口配置留在本机认证系统，不放公开仓库、截图或问题报告。

## 可以不出镜、不录口播吗？
可以选择授权素材、解释动画和概念镜头；旁白可以使用已配置、获授权的配音工具。也可以做无旁白作品。对应工具、费用、声音与素材许可由你自行准备，仓库不附带私人音色、音乐或成片素材。

## 开源是不是全程免费？
代码与技能按 MIT 许可开放；模型、配音、生视频和其他服务可能收费。第一份文字练习不调用额外媒体服务，但助手本身仍可能收费。需要付费生成时先核对具体方案与预算。

## 有配置 JSON，是不是填完自动执行？
不是。`project.example.json` 是交接记录示例，当前工具不会消费它或自动调用服务。空值表示未配置，不能填上字段就认为获得了授权。

## 可以保证爆款吗？怎么反馈问题？
不能保证流量。可以改善流程与检查，但选题、素材、表达和平台表现都要实际验证。反馈时给出系统、客户端版本、操作步骤、脱敏错误和预期结果。不要发密钥、私有路径、真实素材或账户截图；见[安全说明](../SECURITY.md)。
