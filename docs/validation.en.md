# Validation scope

[简体中文](validation.md) · [English home](../README.en.md)

Publication checks cover:
1. Names, frontmatter, UI metadata and local references for the 11 skills; matching English instructions and reference templates.
2. Controlled Python tests: subtitle format, overlap and bounds; source hashing and no-overwrite behavior; installation conflicts and symlinks; privacy scanning and the publication allowlist; preserving bilingual files during installation.
3. A full repository privacy scan plus a publisher-local private deny list. Private reports stay outside the repository.
4. Read-only external review of public documentation and tools when an actual report is obtained. Record decisions locally; do not claim a review passed without a valid result.

These checks cover packaging, tools and instructions. The fictional exercise explains inputs and outputs; it does not establish that all 11 skills passed complete video-production trials. They do not by themselves verify client discovery, cloud voice generation, paid video generation, cross-platform rendering, real listening, independent visual review or audience outcomes. Validate representative clips and actual observations in your own environment when enabling tools.

For improvements, record version and interval, expected/actual behavior, causal evidence, minimal fix and recheck. Update skills from reproducible findings that change future decisions.
