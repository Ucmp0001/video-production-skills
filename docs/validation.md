# 验证范围

[English](validation.en.md)
仓库的发布检查包括：
1. 11 个 skills 的命名、frontmatter、UI 元数据和仓库内引用检查，以及英文说明与参考模板齐全检查。
2. Python 工具的受控测试：SRT 格式、交叠与越界；源文件哈希及不覆盖；安装冲突与软链接；敏感信息扫描及发布允许清单；安装时保留双语文件。
3. 仓库全文隐私扫描，以及发布侧额外的私有禁止词检查。报告仅留在发布者本机。
4. 外部模型对公开文本和工具实现的只读审查，若取得有效报告则在本机记录处理；未取得不得声称通过。

以上属于包装、工具与方法说明的检查。虚构案例用于理解输入输出，不代表 11 个技能分别通过完整视频生产实测。尚未据此验证不同客户端自动发现、云配音、付费生视频、跨平台渲染、真实试听、独立审图或传播效果。启用具体工具时，应在自己的工程中做代表片段与实际观察验证。

持续改进时，先记录当前版本与时间段、预期/实际、原因证据、最小修复及复检。只有能复现且改变后续决策的经验才更新技能。
