# Cover brief

[中文](cover-brief.md)

| Input | Actual information |
|---|---|
| Final copy and payoff | Subject, conflict/relationship, verified facts, qualifiers and answer locations |
| Platform | Required ratios, safe areas and thumbnail context |
| Brand | Existing name, Logo, style and permissions |
| References | Images actually viewed; visible features to adopt or avoid |
| Assets | Acquired files and rights; conceptual generation plan |
| Creator/tools | User selection, real capabilities and output formats |

State one IDEA. For each direction, describe visual relationships, photography/materials, composition, type hierarchy and mobile risks; explain the chosen direction. Make titles, subtitles and labels clear without sacrificing qualifiers to a word count.

Save the concept, text-free master, editable typography, actual platform exports and source/rights/hash manifest. Keep director self-check and independent review separate.
