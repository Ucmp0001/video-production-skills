# 封面 Brief
| 内容输入 | 要填写的实际信息 |
|---|---|
| 定稿及兑现 | 主体、冲突/关系、已核验事实、限定和兑现位置 |
| 平台 | 本次目标比例、安全区和缩略图情境 |
| 品牌 | 用户已有名称、Logo、风格与许可 |
| 参考图 | 实际读到的图片、采用/不采用的可见特征 |
| 素材 | 已取得文件与权利、概念生成计划 |
| 主创/工具 | 本次指定、真实能力与输出格式 |

## 提案与交付
一句 IDEA；各方向的视觉关系、摄影/材料、构图、文字层级、手机可读风险；选方向理由。
主标题/副标题/对象标签先说明白，不为字数牺牲限定。
保存 concept、无字 master、可编辑排版、每个平台的实际图、来源/权利与哈希清单。导演自校和独立审图分开。
