# Generated conceptual B-roll

[中文 / canonical entry](SKILL.md)

Use for concepts that relevant real footage or a simple explanatory visual cannot express well. Skip when the user rejects generated video or requests subtitle/Logo-only changes. Generated media is not news evidence and must not fabricate real actions, transactions or events.

## Prepare a specific plan
Use the [generation and recovery plan](references/generation-plan.en.md) to record purpose, conceptual nature, visual event, reference rights, actual provider/model, duration per group, aspect ratio, native resolution, count, unit-price evidence, total budget and alternatives.

For short/standard videos, up to three groups can be an initial budget suggestion; fewer may suffice. This adjustable suggestion does not override the user. If used at the opening, show a clear subject in the first frame and concrete change in the first three seconds, consistent with narration and payoff. Count it within the existing plan.

Prompts specify subject, action, camera, material/light, initial/final states and misleading implications to avoid. Add exact text, numbers, Logos, charts and UI in postproduction where possible. Exclude private accounts, paths, tokens and unauthorized assets.

## Submission and recovery
Check installed official client help or official API documentation; never invent flags. Where dry-run is available, inspect actual provider/model/resolution fields without submitting a paid task.

Existing authorization covers only the same specific plan and budget. Explain and obtain corresponding confirmation for a new paid plan or material changes to prompts, references, counts or costs. “Make a video” is not unlimited retry authorization. Unknown costs cannot be accepted as within budget.

When a request times out or its outcome is unclear, recover/query/wait/download the same task using its ID or request fingerprint before resubmitting. Track cumulative retry cost and stop at the user's cap. Query network errors do not by themselves establish generation failure.

## Inspect original outputs
Retain sanitized receipts, task state, original hashes, measured dimensions/aspect/duration, actual model and cost. For requested native 2K/4K, compare current official size specifications and actual receipts. Without a size table, mark verification pending. Prompt text saying “2K” and local upscaling do not prove native resolution.

Watch the entire intended interval for action, deformation, subject continuity and joins; listen when audio or sync matters. Model names, success receipts and dimensions do not establish visual quality. Prefer rearranging existing assets or making explanatory graphics over endless resubmission. Keep AI provenance internally and apply current local/platform disclosure requirements.

Deliver plans, prompts, budget/authorization mapping, sanitized task records, originals, selected intervals and inspection scope. Use the existing local authentication system; do not embed credentials.
