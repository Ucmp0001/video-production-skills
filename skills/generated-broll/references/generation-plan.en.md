Unknown cost is not free. When a client lacks a relevant parameter, inspect official requests/receipts instead of inventing a flag.

## Task state
Prepared → submitted (task_id) → running → complete → downloaded/inspected.
Unclear outcome → recover original task → query/download.
Explicit failure → diagnose recoverability → limited retries within remaining budget and the same authorized plan. Material plan changes require an updated explanation and confirmation.

Record whether each attempt incurred a new charge, task ID, request fingerprint, sanitized receipt, cumulative cost and query scope. Do not retain Authorization values or signed download URLs in the handoff.

## Original-output acceptance
Hash, measured dimensions/duration/ratio, official native-spec basis and actual model. Inspect subjects, action, structure, continuity, opening/ending, composition and caption/Logo space across the full intended interval. Missing observation remains pending. Conceptual provenance and public disclosure are separate tasks.
