## 服务状态
准备 → 已提交(task_id) → 运行 → 完成 → 已下载/已验。
请求结果不明 → 恢复原任务 → 查询/下载。
明确失败 → 判断原因与可恢复性 → 在剩余预算和同计划授权内有限重试；计划实质改变则先更新说明与确认。
记录每次尝试是否新计费、任务 ID、请求指纹、净化回执、累计费用与查询范围；不保存 Authorization 或签名下载 URL。

## 原片验收

全拟用区间看主体、动作、结构、连续性、首尾、构图、字幕/Logo空间；观察缺失保留待项。生成片只表达概念，来源和公开声明分别处理。
