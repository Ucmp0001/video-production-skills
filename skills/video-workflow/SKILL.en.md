# Video production workflow

[中文 / canonical entry](SKILL.md)

Start from the user's selected version and existing artifacts. Identify whether this is a new video, continuation, interview excerpt, subtitle repair or cover-only change. Do not restart stable stages.

## Inputs and routing
Establish audience, purpose, aspect ratio, existing script/audio/assets, current version, tools and authorization. Respect the user's paths, voice, models and style. Record reversible assumptions for missing details; actions requiring spending or external publication remain pending until appropriately authorized.

Use the [project card](references/project-card.en.md). Record real files and specific gaps, reusing existing project state rather than requiring empty forms. Preserve originals and earlier outputs.

Route only missing stages. Use these skills when installed; otherwise work from the inputs/outputs below or state the required capabilities, without pretending an unavailable skill was invoked:
- Interviews or recordings: video-source-index for provenance and usable intervals.
- New story: evidence-story-script for claims and opening promise, then video-shot-planner for coverage.
- Mechanisms: explainer-motion for state changes; generated-broll only for conceptual shots.
- Original or authorized voice: voice-subtitle-sync for measured timing and captions.
- Covers: cover-art-direction, then cover-independent-review in a separate review context that actually views the files.
- Final output: video-release-qa for the current export and platform copy.
- Reference learning only: video-reference-study, without automatically producing a video.

## Production and acceptance
Combine relevant real footage, concise evidence cards, 2D relationships and 3D objects as needed, without fixed quotas. The first image and sentence ask the same question; the body answers it. Use generated opening shots only when that route was chosen, within the existing budget.

After script approval, preview a complete representative event or risky opening transition with actual audio before expanding the approach. Tool checks establish only the technical properties they inspect. If playback, listening or image inspection is unavailable, continue independent work and mark the affected acceptance checks pending.

Track content, technical checks, still images, continuous motion, sound, covers, rights and publication conditions separately. A review version can be delivered with explicit gaps. Call the production package complete only when required production checks are complete. Publish only within the user's explicit existing authorization.

## Revisions and delivery
Audio changes require updating affected captions and shots. Shot changes require checking movement, transitions and related cover promises. Cover changes invalidate relevant visual reviews. Subtitle/Logo-only edits need focused checks of affected parts.

Deliver the current version and clickable paths to the video, project, subtitles, covers, script and sources, with actual status and next action. Do not default to ZIP archives or expose credentials in indexes.
