# Project card and delivery status

[中文](project-card.md)

Merge into existing records. For unknown fields, record the gap and next action instead of invented paths or times.

| Field | Record |
|---|---|
| Current work/version | User-selected files, hashes and version |
| Scope | New / continuation / interview excerpt / local revision |
| Audience, purpose, platform | Actual choices for this task |
| Content and sound | Latest stable script, original/TTS status, measured duration |
| Assets | Sources, rights, intended intervals and gaps |
| Tools and creator | Actual renderer, model, capabilities and interfaces |
| Clocks | fps and global/shot/source mappings |
| Authorization and cost | Specific plan, budget and external-action scope |
| Next stage | Missing work, inputs and expected artifacts |

| Current file/hash | Content | Technical | Stills | Motion | Sound | Cover | Rights/publication |
|---|---|---|---|---|---|---|---|
| Selected version | Complete / pending / not applicable | Same | Same | Same | Same | Same | Same |

For each check, record the actual method, observer, observed interval and evidence. Explain “not applicable.” Pending items need a minimal next action. Keep production status, publication conditions and actual publication status separate.
